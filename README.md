# Task Dashboard

React frontend internship project. Features: Login, Register, Task CRUD with file attachments, filtering/sorting, skeleton loading, animations, icons.

## Run
```
npm install
npm run dev
```

## Demo credentials
Register any account — data persists in localStorage.

## Tech
- React 18 + Vite
- React Router v6
- Framer Motion (animations)
- Lucide React (icons)
- React Loading Skeleton
- React Toastify
